클룩 할인코드 적용 순서

앱 전용 할인코드와 결제수단 조건 할인코드는 누르는 순서가 조금 다릅니다.

클룩 앱 전용 할인코드 넣는 순서

  1. 클룩 앱 설치·로그인BETTERONAPP과 HOTELONAPP은 웹에서 결제하면 적용되지 않으니 앱으로 들어갑니다.
  2. 상품·옵션 선택패키지, 이용 날짜, 인원을 고르고 결제 화면으로 넘어갑니다.
  3. 프로모션 코드 칸에 입력결제 화면의 프로모션 코드 칸에 할인코드를 넣거나, 미리 '내 쿠폰'에 등록해 둔 할인코드를 선택합니다.
  4. 결제 요약 확인할인 줄에 금액이 찍혔는지 보고 결제합니다. 할인 줄이 없으면 아래 '할인이 안 될 때'를 확인하세요.

클룩 결제수단 할인코드 넣는 순서

  1. 결제 통화 확인KKP5000은 원화(KRW) 결제에서만 적용되니 표시 통화를 원화로 맞춥니다.
  2. 할인코드 등록KKP5000, KKPJPHOT4M, MCWORLD5OFF 중 해당하는 할인코드를 등록하거나 결제 화면에 입력합니다.
  3. 결제수단 선택카카오페이 할인코드는 카카오페이를, MCWORLD5OFF는 월드 등급 마스터카드를 고릅니다.
  4. 지금 결제 선택MCWORLD5OFF는 나중에 결제 예약에 적용되지 않으니 바로 결제하는 방식으로 진행합니다.

클룩 할인코드 자주 묻는 질문

클룩 할인코드 두 개를 같이 쓸 수 있나요?

같이 쓸 수 없습니다. 한 결제에는 할인코드 하나만 들어가므로 금액별 계산 표에서 가장 큰 할인액이 나오는 할인코드 하나를 고르세요.

클룩 신규 회원 할인코드는 웹에서도 되나요?

되지 않습니다. BETTERONAPP과 HOTELONAPP은 앱 결제 전용이라 PC나 모바일 웹에서 입력하면 할인이 붙지 않습니다.

월드 레전드, 월드 엘리트, 월드 셀렉트, 월드 컨슈머 등급 마스터카드가 대상입니다. 카드 앞면에 World 표기가 없는 일반 등급은 제외되니 카드사 앱에서 등급을 확인하세요.
